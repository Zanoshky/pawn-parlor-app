This repo is the public home for Pawn Parlor users: the user guide, bug reports and feature requests. The app itself is proprietary and its source is not here. On Google Play it is called Board Card Games: Pawn Parlor.

## What it is

Pawn Parlor is a table full of classic board and card games. Pick a game and sit down against a bot, or invite a friend. It is a Trusted Web Activity of [games.zanoski.com](https://games.zanoski.com), so it runs on Chrome.

- Free: all 66 games against bots, the daily challenge, live games, leaderboards and replays.
- Online play against people (lobbies, invites by link or QR, ranked games and chat) needs the Pawn Parlor Online subscription, 0.99 a month, bought inside the Android app through Google Play only.
- The website stays free in a browser and does not sell anything.

## Quick start

1. Install Pawn Parlor from Google Play. It runs on Android 10 or newer and needs Chrome.
2. Open All games, pick a game and tap Play vs Bots. No account needed.
3. For people, open Settings, Account and tap Subscribe with Google Play.

## Report a bug or ask for a feature

1. Search the [open issues](https://github.com/Zanoshky/pawn-parlor-app/issues) first. If yours is there, add a thumbs up or a comment.
2. Otherwise open a [bug report](https://github.com/Zanoshky/pawn-parlor-app/issues/new?template=bug_report.yml) or a [feature request](https://github.com/Zanoshky/pawn-parlor-app/issues/new?template=feature_request.yml).
3. Add your app version, phone model, Android version and Chrome version, and a screenshot if you can. Crop out anything private first: issues are public.

No GitHub account? Write to support@zanoski.com.
